# SOC-Tools - 3 Tools by Ayesha
Day 30 Demo - SOC Level 1 Analyst Project

## Tool 1: Log Analyzer
Checks system logs and finds failed login attempts.

## Tool 2: IP Checker  
Checks if an IP is malicious using AbuseIPDB logic.

## Tool 3: File Integrity Checker
My best tool. It creates a Golden hash of files. If any new file like hacker.txt is added or any file is changed, it gives [Alert] / [New] / [Safe].

This project shows how a SOC L1 monitors logs, IPs, and files.
